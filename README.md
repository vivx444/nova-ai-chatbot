# 🤖 Nova AI Chatbot

Nova is a beginner-friendly chatbot built using Python.
It demonstrates basic conversation logic and user interaction.

## ✨ Features

- Friendly greetings and responses
- Remembers your name during a session
- Performs basic arithmetic calculations
- Tells programming jokes
- Provides a help menu

## 🛠️ Technologies Used

- Python 3
- Python standard library

## 🚀 How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

   python main.py

## 📚 What I Learned

- Python functions
- Conditional statements
- Loops
- Exception handling
- Basic expression parsing

## ⚠️ Limitations

Nova is a rule-based chatbot. It does not use a
trained large language model and has limited responses.
